Customising

Open Tools > Scripts > MagmaRita > Settings... to choose the key and brush preset for each slot, plus the scrubby-zoom sensitivity.

Settings are stored in magmarita.json in Krita's resource folder (%APPDATA%\krita on Windows, ~/.local/share/krita on Linux).

Menu

  • Apply Magma keymap - re-applies the shortcuts.
  • Restore previous shortcuts - restores the newest backup.
  • Settings... - configure the preset slots.
  • About MagmaRita - version and config path.

If a key does not work

  1. Restart Krita after installing or changing shortcuts.
  2. Check the log at %LOCALAPPDATA%\magmarita-diag.log.
  3. The old "Scrubby Zoom" plugin is disabled automatically so it does not fight MagmaRita over the Z key.

Palette

Open it from Settings > Dockers > MagmaRita. It shows quick tool buttons, the ten brush-preset slots (click to activate, right-click to rebind or clear), Pen Pressure and Lock Alpha toggles, brush Size/Opacity sliders, and Settings / Apply buttons.

Pen Pressure toggles Krita's "Use Pen Pressure" - whether the pen's pressure affects the brush (size and opacity together). Per-axis pressure curves live in each preset in Krita's brush editor.

Number keys zoom or rotate the canvas?

Krita's Canvas Input Settings (a different system from the keyboard shortcuts!) binds the number keys to Zoom/Rotate by default. MagmaRita removes those bindings from your active canvas-input profile so the number keys belong to MagmaRita. If it ever returns (for example after switching the input profile), run Tools > Scripts > MagmaRita > Apply Magma keymap again.
