Magma keybinds for Krita

MagmaRita helps you move from Magma to Krita. Magma's tool presets live on the number keys (1 dropper, 2 small eraser, 3 pen, ...), so you stop setting every tool up by hand - plus a Magma-style palette docker, scrubby zoom (Z), canvas rotation (R) and a straight-line assist (Ctrl).

Unofficial. Not affiliated with or endorsed by Magma or the Krita Foundation.

Common questions

  • Is there a Magma-style keymap for Krita? Yes - that is exactly what MagmaRita is.
  • Why do my number keys zoom the canvas? Krita's Canvas Input Settings. MagmaRita clears those bindings.
  • Scrubby zoom for Krita? Hold Z and drag.
  • Install: install.bat / ./install.sh / python install.py.
