MagmaRita Scrubby Zoom

Hold the shortcut (H by default) and drag horizontally to zoom relative to the current zoom level.

  • The zoom anchor is taken from Krita's real zoom value, so it starts from where you are instead of jumping.
  • The last zoom is remembered per document.
  • Sensitivity is configurable (pixels per doubling) in Tools > Scripts > MagmaRita > Settings....
