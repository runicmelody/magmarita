# Changelog

## 0.6.0 - 2026-10-13
- Scrubby zoom remapped to **H** (was Z), and it is now **configurable**:
  magmarita.json "zoom_key" and the Settings dialog ("Scrubby zoom key").
- Flip canvas stays on M (H is now zoom).
- Palette docker (0.5.0), canvas-input digit fix (0.4.0) included.

## 0.5.0 - 2026-10-13
- MagmaRita palette docker (Settings > Dockers > MagmaRita): quick tool
  buttons, ten brush-preset slots with thumbnails, Size/Opacity sliders.

## 0.4.0 - 2026-10-13
- Fixed number keys zooming/rotating the canvas (clears Krita's Canvas Input
  Settings digit / = - + bindings).

## 0.3.0 - 2026-10-13
- Configurable preset slots (magmarita.json + Settings dialog).
- Runtime keymap application, digit fallback filter, plugin manual.

## 0.2.0 - 2026-10-12
- Bundled a fixed Scrubby Zoom plugin.

## 0.1.0 - 2026-10-12
- First release.
